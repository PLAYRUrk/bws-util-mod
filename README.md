# BWS Util Mod

Клиентский Forge-мод (`modId`: `bws_util`) для BedWars и лука в `Minecraft 1.21.11`.

Текущая версия: `1.5.1`.

## Что умеет мод

- Баллистический прицел для лука с zeroing.
- Режимы прицела `MANUAL` и `AUTO` (с упреждением по движению цели).
- BedWars overlay: список угроз, союзники, таблица `TEAM POWER`, статус и тип защиты кроватей.
- Круговой компас-радар в правом верхнем углу.
- Лог событий матча по чату сервера (разрушение кроватей, выбывание команд).
- Предупреждения по центру экрана: `FIREBALL INBOUND` и `RETREAT` (вектор безопасного отхода),
  с опциональным звуком.
- Аварийная подмена слота на блоки при падении в пустоту (отключается в настройках).
- Опциональная интеграция с внешним автокликером
  [PLAYRUrk/AUT-CLK](https://github.com/PLAYRUrk/AUT-CLK).

## Совместимость

- Minecraft: `1.21.11`
- Forge: `61.1.5` (диапазон `61+`)
- Java: `21`
- Тип: client-side
- Конфиг: `config/bws_util-client.toml`

## Установка

1. Собрать мод:
   - Windows: `.\gradlew.bat build`
2. Взять JAR из `build/libs`.
3. Положить JAR в папку `mods` Forge-клиента.
4. Запустить игру и настроить бинды/параметры.

## Клавиши по умолчанию

| Клавиша | Действие |
|---|---|
| `Z` | Открыть **General Settings** |
| `O` | Включить/выключить Scope Overlay |
| `M` | Переключить `MANUAL` / `AUTO` |
| `B` | Включить/выключить BedWars overlay |
| `=` / `-` | Контекстное действие (см. ниже) |

Контекст для `=` / `-`:

- при активном прицеле в режиме `MANUAL` меняют `zero_distance` (`±5`, диапазон `10..200`);
- при включенном BedWars overlay в режиме `AUTO` (или когда прицел неактивен — например, лука
  нет в руках) меняют масштаб радара (`24..96` блоков, шаг `4`).

Изменение `zero_distance` с клавиш сразу записывается в конфиг.

## Экран настроек (`Z`)

### Scope

- `Zero Distance` (`10..200`)
- `Reticle Color` (пресеты)
- `Show only while drawing`
- `Show range markers`
- `Show rangefinder`
- `Show charge bar`

### BedWars helper + sound

- `Fireball Threat` (on/off)
- `Bridge Fight Helper` (on/off)
- `Warning sounds (master)` (on/off)
- `Fireball warning sound` (on/off)
- `Void warning sound` (on/off)
- `Match log (chat events)` (on/off)
- `Emergency block swap` (on/off)
- `Fireball volume` (`0..100`)
- `Void volume` (`0..100`)

Настройки сохраняются на диск при закрытии экрана.

## Scope Overlay

### `MANUAL`

- Крест с учётом `zero_distance`.
- Stadia marks (метки дальности; дубликаты дистанций отфильтрованы).
- Rangefinder (`◎ N.Nm`) — считается раз в тик, а не каждый кадр.
- Label пристрелки (`⊕ Xm`).
- Опциональный charge bar.

### `AUTO`

- Захват ближайшей цели в конусе 15° при натяжении.
- Расчёт lead-point по движению цели (две итерации по времени полёта).
- Ромб упреждения с подписью цели и дистанцией.

Расчёт баллистики (`ArrowPhysics.zeroAngle`) мемоизируется по квантованной сетке
(дистанция 0.5 блока, заряд 0.02) — иначе бинарный поиск с потиковой симуляцией выполнялся бы
десятки раз за кадр.

## BedWars Overlay (`B`)

Левая верхняя панель + круговой радар справа сверху.

### Основная панель

- Заголовок `BEDWARS` + индикатор `LIVE` / `SCAN`.
- `ENEMIES` / `TEAM` списки. Секция `TEAM` скрывается только если игрок реально один в своей
  команде по скорборду (проверка по составу команды, а не по числу врагов на карте).
- Приоритетные threat-строки с визуальным акцентом.
- Таблица `TEAM POWER`:
  - относительная сила команд,
  - теги `(you)`, `→HUNT`, `THRT`,
  - статус кровати и код защиты (`UNK`, `---`, `WOL`, `TER`, `END`, `OBS`),
  - оценка сложности пробития (`EASY` / `MID` / `HARD`).
- `MATCH LOG` — последние 3 события матча.

### Формат строки игрока

- направление до цели (`↑ ↓ ← → ↗ ↘ ↖ ↙`);
- укороченный ник (с `!`, если игрок натягивает лук);
- дистанция, разница высот (`+N/-N`) и ETA до контакта;
- класс брони по **лучшей надетой части** (`N/D/I/C/G/L`).

### Радар

Круглый, вращается вместе со взглядом — верх диска всегда «вперёд».

- Буквы `N/E/S/W` по ободу дают абсолютное направление.
- Два кольца дальности на `1/3` и `2/3` текущего радиуса — масштабируются вместе с зумом.
- Враги — треугольники, ориентированные по вектору движения; стоящие на месте рисуются точкой.
  Оранжевый цвет = натягивает лук.
- Враги за пределами радиуса **прижимаются к ободу** приглушённым цветом, а не скрываются.
- Геометрия карты — приглушённые точки с категоризацией: башни/стойки, стены, мосты/тонкие
  дорожки, обычная поверхность. Всё жёстко обрезается по кругу.
- Подпись под диском: число врагов в радиусе и текущий радиус (`2E · 48m`).

### Предупреждения

Постоянной текстовой панели в правом верхнем углу больше нет. Остались только центральные
предупреждения у прицела:

- `FIREBALL INBOUND` — мигает, когда огненный шар реально сближается с игроком
  (ETA ≤ 2.4 с или дистанция ≤ 18 блоков), плюс опциональный звук.
- `RETREAT ↙ 2v1` — вектор безопасного отхода. Появляется только в вероятно проигрышном бою
  (численный перевес, низкое HP, перевес по HP, суммарное давление) и выбирает направление
  с учётом пустоты под ногами.
- Bridge/void helper остался как звуковое предупреждение — визуального текста у него больше нет.

### Логика кроватей

- Скан идёт по загруженным чанкам вокруг игрока (радиус 8 чанков, ±48 блоков по Y).
  Каждая секция чанка сначала проверяется через палитру (`LevelChunkSection.maybeHas`), поэтому
  секции без кроватей не читаются вообще.
- Тип защиты оценивается по непосредственной оболочке кровати: боковые стороны + верх.
  Блоки **ниже уровня кровати не учитываются** — материал острова не влияет на оценку.
- Есть стабилизация, чтобы уменьшить ложные скачки типа защиты при подгрузке чанков.
- Индекс «цвет → кровать» перестраивается только по завершении прохода, поэтому кровати одного
  цвета не «слипаются» во время скана.

### Лог событий матча

Мод разбирает чат сервера и распознаёт разрушение кроватей и выбывание команд по ключевым
словам (русские и английские формулировки). Команда определяется в первую очередь по цвету
стиля сообщения, и только затем по цветовому слову в тексте.

Главная польза не в самой ленте: раньше команда, чья база вне радиуса скана, навсегда
оставалась `UNK` в `TEAM POWER`. Чат даёт факт разрушения кровати на любой дистанции. При этом
чат может только пометить кровать разрушенной — «живой» он её объявить не может, так что
ложноположительного «кровать цела» эта логика создать не способна.

## AUT-CLK integration

Мод поддерживает bridge-протокол `AUT-CLK` через `127.0.0.1:25566`:

- отправляет `ac_control` (включая `lmb_enabled` / `rmb_enabled`);
- читает `ac_status` и синхронизирует состояние каналов;
- использует защиту от stale-статусов и reconcile-цикл, чтобы каналы не «залипали»
  в выключенном состоянии.

Автоподавление каналов в моде:

- при открытом GUI подавляются LMB/RMB;
- если в руках лук — подавляются LMB/RMB (legacy-поведение);
- для consumable-предметов и огненных шаров подавляется RMB.

Чтобы интеграция работала:

1. Запустить `AUT-CLK`.
2. Включить `Control bridge` (`Enable`, не `OFF`).
3. Запустить Minecraft с модом.
4. Убедиться, что в `AUT-CLK` статус `Bridge: Connected`.

## Архитектура (кратко)

- `ScopeOverlay` — рендер и логика прицела (`MANUAL`/`AUTO`).
- `BedWarsOverlay` — BedWars HUD, радар, предупреждения, bed-scan.
  **Вся игровая логика живёт в `tick()`; `render()` только рисует готовый снимок.** Это важно не
  только для FPS: рендер пропускается при открытом экране, поэтому логика в нём замолкала ровно
  тогда, когда игрок открывал чат.
- `MatchTracker` — разбор чата и состояние матча.
- `TeamColors` — сопоставление команды и цвета кровати (общее для оверлея и трекера).
- `ClientGameEvents` — клавиши, tick-логика, сброс состояния при смене сервера, контекст `+/-`,
  управление bridge-подавлением.
- `AutoclickerBridgeClient` — TCP-клиент к `AUT-CLK`, sync/reconcile каналов.
- `ScopeConfigScreen` / `ScopeConfig` — GUI и клиентский конфиг.
- `GuiRendererMixin` — единственная точка входа рендера оверлеев.

## Быстрый чеклист

1. `O` включает/выключает scope, `M` переключает `MANUAL`/`AUTO`.
2. В `MANUAL` проверить `=` / `-` (zeroing), в BedWars (`B`) — масштаб радара.
3. `Z` открыть General Settings, проверить тумблеры и что настройки сохранились после перезапуска.
4. Проверить радар: повернуться на 360° (буквы компаса идут по кругу), зум (кольца
   перестраиваются), врага за радиусом (прижат к ободу).
5. Открыть чат при летящем фаерболе — звук должен сработать.
6. Сменить сервер — таблица команд и кровати должны обнулиться, масштаб радара сохраниться.
7. Нажать `F1` и убедиться, что HUD/оверлеи скрываются.

## Известные ограничения

- AUTO-захват работает в конусе и в плотной толпе может выбрать не идеальную цель.
- Расчёты ETA/угрозы основаны на клиентской дельте движения и чувствительны к лагам.
- Bed-аналитика ограничена радиусом скана и подгрузкой чанков; вне этого радиуса статус кровати
  известен только из чата.
- Лог матча опирается на формулировки конкретного сервера. Нестандартная фраза просто не
  распознается — мод откатывается к данным скана.
- Скан кроватей видит только загруженные чанки, поэтому при малом render distance дальние базы
  могут не попасть в выборку.
